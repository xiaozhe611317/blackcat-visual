# 一次答完的角色问卷

仅在新建角色或用户要求重新选设定时读取。题目和 Q 编号固定；按已知信息预填，整张一次展示，不临时随机编题、不逐题追问。用户只改想改的项；每题都可答“自定义：……”或“交给 AI”。先用用户提供的参考与文字，不把 Link 或其他既有角色当作通用答案。

表头：**角色名字：____　总文件夹：____**。已有名字、路径或参考图直接列出；没有名字可先用工作名，路径沿用用户已指定的项目目录。可附一行自由补充，不另开问卷。

回复可用 `Q01A Q02C Q03B …`；未答项标为“交给 AI”，依据用途和其余答案补全，并在设定卡简短标明。推荐组合仅供起步，例如自然日常可参考 Q11A＋Q12A＋Q13A＋Q14A；不将推荐当作用户选择。用户已给“全自动做完整包”等指令时，预填对应节奏，不再次要求选择。

## 从答案生成设定

- Q01–Q08 → 角色身份与轮廓。发型发色默认可变；只有用户指定为固定特征时才列为锚点。不要从肤色推断国籍或族裔，不虚构精确身高和五官数值。Q04 是中性基调，不能禁止笑、哭等表情变化。
- Q09–Q10 → 最多 2–3 个清楚的锚点。先保留中近景可认出的轮廓或标记，微小虹膜环等细节只作辅助。每项写明形状、颜色、位置、**角色本人左/右**、固定或默认、合理遮挡规则。AI 选出的具体设计先出现在设定卡里，不把它说成用户原话；痣、斑纹等身份标记不随 Q10 的饰物规则摘换。
- Q11–Q12 → 默认服装、妆容、发型与配色。妆容未指定时从角色形态和用途给出适合的简短默认值；默认服装和画风不进入随机池。
- Q13–Q15 → 默认风格、材质光线和比例。画风属于可变外观，不混入身份禁止项；混合选择写清具体表现，不强制退回单一画风。尺寸使用当前工具支持的尺寸，不许诺未支持的精确输出。
- Q16 → 写出 3–5 个兼容场景，以及少量动作、时间、构图；仅这四项允许无提示词随机。Q17 的限制分到身份、生图通用或当前风格，换风格时只移除旧风格特有规则。
- Q18 → 沿用授权节奏。默认母版、整包两次审核；已授权全自动则自查母版后继续整包，最后统一展示。无论节奏，AI 自查不等于用户认可；用户选择仅文字时不启动生图。

非人形角色仍用同一张问卷：Q05–Q08 改读为头部/眼部、头顶轮廓、毛皮/外壳、身体比例；确实无对应结构时预填“不适用”，不造人类五官。服装、妆容和饰物也可不适用。引用原 Q 编号即可，不增加分支题库。

输出一张简短设定卡：**身份｜固定锚点｜默认外观与风格｜随机范围｜拟生成资产与张数**。明显矛盾会影响身份时才一次集中澄清；其余用合理解释继续。将完整设定写入 `templates/character.md` 对应结构，保留原答案到过程记录。
