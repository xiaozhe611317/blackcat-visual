# 环境能力与执行方式

规格参数与真实输出的适配按 [image-specs.md](image-specs.md)。本版只提供声明式工具能力契约，不内置某家图像模型的调用器；要依当前工具说明填写。独立身份控制需另查单人/多人、逐人绑定、必要参考数量；不因支持 PuLID/参考权重就宣称支持 5–8 人独立锁脸。

这些是执行分支，不是厂商或模型排行榜。模型能力会变化，只依据当前接口、已知工具说明和真实返回记录；未知写未知，不根据 Claude、Grok、豆包等名称推断能力。对话模型负责理解和编排，图像工具负责实际出图，两者可以不是同一家。

## 首次运行的简短检查

| 当前环境实际能做什么 | 采用方式 |
|---|---|
| 项目明确选择轻量接入，能读写项目文件、生图与传参考图 | 项目文档接入；采用下文轻量执行规则，不要求原生登记脚本 |
| 需要正式登记或继续已登记批次，具备读写文件、Python 3.10+、Pillow、生图与传参考图 | 完整 Agent 模式，使用脚本记录；由 Agent 调用环境图像工具 |
| 能生图、传图片，但不能运行脚本/读本地目录 | 便携聊天模式；上传 MD、实际图片及状态表，人工或平台保存结果 |
| 默认工具不能生图或传参考 | 先检查当前环境已配置的替代工具；仍不可用再交接或暂停 |
| 只有文字聊天 | 输出提示词、参考图编号/用途与任务表，不宣称完成出图、看图或视觉 QA |

只检查本轮必要能力：读取角色 MD、查看图、传图、获得真实输出、保存记录、编辑目标、多图输入数量/大小、是否支持局部编辑、批次/并发限制。可用/不可用/未知三态即可。没有必要预先探测所有服务，更不要为探测先生成收费测试图。

## 项目文档接入与轻量执行

项目或用户明确选择轻量流程时，沿用项目目录和审核约定，不运行原生登记/批次 CLI，也不手工模拟它们的多层文件结构。未明确选择时沿用现有项目方式；正式登记与已有原生批次仍按完整协议。轻量记录不是原生 batch.json，不能声称可直接用原生 CLI 续接。

- 本批先读取当前角色 MD、打开必要参考并核对参考完整性，再缓存内容和已看图结论。相同文件、角色版本、要求和工具接口未变时复用；每次调用仍实传本图必要图片并核对编号归属。上下文已丢失或有变化证据时，仅重读受影响资料。
- 轻量批次用一份批次总记录：共享要求、参考路径/哈希/用途、逐项 ID 与轮次、每项实际完整提示词和实传参考编号、工具/可见参数、调用与结果状态、原始输出路径/规格/哈希、简短 QA 和用户决定。逐项提交前和结果返回后更新状态以便续接；共享内容保存一次，总览引用结果，不复制全文。提交给工具的每张提示词仍完整，不用“同上”。
- 每张做一轮实际视觉检查，覆盖身份、可见锚点、画风、形体、需求和纹理；同框逐人检查并核对场景连续性。不同模块的清单合并执行。细节看不清或发现疑点时补看相关区域；图像、参考或要求改变时复查受影响项目。通过项用简短观察，问题项说明具体位置，不为凑记录重复开图。
- 保存真实原文件后，集中读取格式、像素、模式、文件大小及 SHA-256；透明需求额外查真实透明像素。移动/复制后比对对应文件哈希，修改后重查受影响规格和视觉项目；其他文件不重复验证。读不到原文件时标无法验证，不填写通过。
- 用户认可只更新对应状态与原话；已接受的偏差继续保留。纯路径变化不重做视觉 QA，作品认可不自动改变身份参考。历史原生批次继续由原协议维护，不另建平行状态表。

### 时间预算

遵循用户或项目给定的预算、计时起点和超时策略；没有指定时不承诺固定分钟数。记录准备、生图、检查归档三个阶段的实际起止时间、交付结束时间和等待用户的区间；执行总耗时为起点至交付的墙钟时间减去用户等待。工具等待计入总耗时；阶段有交叠时注明，不将阶段时长简单相加。计时事实不足时写未知，不倒推精确原因。

先完成可复用准备，再连续执行授权调用；明确支持并发且限额已知时有界并行，能力不明则顺序调用。等待生成时可处理已返回结果的检查或记录。按项目指定时点或预计超时时报告剩余工作，遵循已选策略继续或交付部分结果，不为赶时间降低规格、省略身份检查或暗增调用。完成 SKILL.md 的交付条件即结束本轮。

## 默认工具与调用边界

使用用户指定工具，否则用当前环境默认工具；不绑定图像模型，不要求特定 API、API Key、种子、LoRA、ControlNet、参考权重或 Python SDK。只有当前接口明确支持且任务需要时才用可选参数。提示词中的画幅是目标，真实尺寸另记；模型名和 seed 未暴露就写“未暴露”。

默认工具不能生图或可靠传必要参考时，先检查当前环境已配置、可用的其它合适图像工具；无新增登录/安装且费用已获授权时可以采用，明确记录实际工具，不把切换冒称原工具。不要为了探测而先调用收费测试图。用户指定“只用某工具”时遵守该限制。

不自动安装服务、不登录、不切换计费账号、不提高付费档位。替代工具涉及新的登录、安装或费用超出已有授权（包括费用不明确）时，先用选择题询问。若已发出一次调用且失败，切换重试仍属于额外调用，遵守集中返工授权；不能借切换工具绕过零自动重试规则。所有已配置工具都不能完成时，让用户选“交接提示词和参考包”或“暂停相关项”，不默默降低身份要求。

引用图上限容不下本图必要输入时，不丢掉某个人的母版。可选方案：用户批准分阶段编辑/合成（额外调用单列预算）、减少本图人数，或换用户允许的工具。参考拼图只有在当前工具可清晰读出每个身份且用户接受风险时使用，不能当作无损替代。

## 真实执行与交接

脚本不是图像生成器，不会在退出后继续工作。完整 Agent 按 batch.md 逐项执行，有并行能力且限额明确才有界并行；默认顺序执行。24 张是计划数量，不承诺单次请求、同时生成或固定耗时。一次 attempt 对应一次调用的一张目标图，避免服务自动 n>1 或自动重试造成数量不明。

提交前检查实际图片编号与提示词映射、工具数量限制、授权和当前状态。先记 batch-dispatch，再真实调用；仅写 dispatch 不算工具已调用。调用后把真实输出和可见元数据回填。断线后查看工具结果/任务 ID；有图则回填，无确切结果则 unknown，不能假定失败重新发送。

跨环境交接最小包：角色 MD、必要真实图片、编号/所属/用途表、场景及镜头、完整逐图提示词、任务 ID/轮次、尚未执行和结果未知清单。图片路径不是图片本身。新聊天缺附件就索要缺图，不以“记得长相”代替参考。不能读取/下载原文件时保留平台链接和可见结果，明确文件归档尚未完成；回收真实文件后继续记录。

记录环境实际暴露的信息，不索要或打包账号凭证。对外分享前剔除本地来源路径、私人文档和无关图片；完整批次含角色素材，不等同于可公开分发的空白 Skill ZIP。

## 便携性边界

核心规则、模板和数据不依赖某家 Agent。agents/openai.yaml 只是可忽略的可选界面元数据。新项目/批次不要求全局配置，旧 v1 的本机绑定仅为兼容保留。

“可在其他环境使用”表示可遵循同一规则并使用其现有能力，不表示所有平台原生识别 SKILL.md、支持脚本、支持 8 人一致性或保证画质；未经真实运行的平台必须标为未实测。
