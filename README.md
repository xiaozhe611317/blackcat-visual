# BlackCat 黑猫视觉

固定角色创建、一致性生图与批量任务编排 Skill。当前版本 **3.1.1**。

本仓库公开提供可复用框架、空白模板、辅助脚本和合成素材测试；不包含任何个人角色、身份参考图片、生成作品、账号凭证或本机运行环境。

## 能做什么

- 创建固定角色：一次问卷、角色文档、身份母版、视图/表情/锚点资产与整包认可。
- 固定角色生图或改图：沿用身份和默认设定，支持临时换装、换画风、随机场景。
- 单/多角色批量：例如 12 位角色每人 2 张，拆为 24 项可追溯任务；冻结参考，支持中断续接和集中返工。
- 固定场景同框：地点、布局和关键物件保持一致，允许换机位；5–8 人逐人检查，不把工具成功当成身份一致。
- 图片规格：比例、像素尺寸、制作档位、背景、格式、构图与留白；共用规格＋逐图例外，保存常用方案。

单张每次新请求确认制作档位，批量每批确认一次。提示词、真实工具参数、参考图归属分开管理；记录要求、实传和实际文件规格。不自动增加预览、精修或重试调用。

## 三种使用方式

1. **完整 Agent Skill**：使用 [blackcat-visual/SKILL.md](blackcat-visual/SKILL.md) 及其完整目录。支持 Skill 的环境通过其技能管理工具加载这个子目录；不要只复制入口文件。
2. **项目文档接入**：项目明确选择轻量流程时，按 [环境适配](blackcat-visual/references/environment.md) 使用项目已有目录和一份批次记录；正式角色登记与已有原生批次仍走完整协议。
3. **普通聊天**：上传 [便携聊天版](docs/黑猫视觉-便携聊天版.md)，同时提供角色文档、必要真实参考图片和场景资料。只有本地路径或旧聊天名称不等于传入图片。

可以直接对助手说：

> 用黑猫视觉，让这 12 个角色在同一个咖啡馆里每人生成 2 张单人图。先统一选择规格，保留逐图例外；先完成独立任务，最后集中列出待修项。

使用用户指定或当前环境默认的图像工具，不绑定 Claude、Grok、豆包、Codex 或某家生图模型。身份参数增强是可选功能，不要求 PuLID；单脸或全局权重不等于多人独立绑定。默认工具能力不足时检查已配置的合适工具；新登录、安装或未授权费用先询问。

## 仓库结构

```text
blackcat-visual/  可安装的 Skill（入口、规则、模板、脚本）
docs/            单文件便携聊天版
tests/           合成数据与流程测试，无真实角色素材
tools/           打包、导出便携说明、独立解压验收
```

脚本负责记录、参数校验与文件核验，不是独立生图服务。实际生成由当前环境的图像工具完成；不提供退出会话后的无人值守生图。

## 本地验证与打包

Python 3.10+；完整脚本使用 Pillow。复用已有环境或创建本项目独立环境，不需要模型权重或图像 API 密钥。

```sh
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
python tools/package_skill.py --out dist/blackcat-visual-v3.1.1.zip
python tools/export_portable.py --out docs/黑猫视觉-便携聊天版.md --replace
python tools/verify_release.py --archive dist/blackcat-visual-v3.1.1.zip
```

Windows 终端建议启用 `PYTHONUTF8=1`。仓库中的 GitHub Actions 仅手动触发，不会在上传时自动使用托管构建额度。

程序通过只证明文件与流程契约，不证明真实图像质量、原生高清、人物相似度或跨平台效果。Claude、Grok、豆包等环境需要按当时实际工具能力使用，未经运行的平台不能声称已实测。
